# PROJ-142 — the ticket

[`01-ticket.md`](01-ticket.md) is the ticket as it arrived: a real bug report, and typical. This
branch holds the code **before** anyone worked on it.

**Try it.** Hand the ticket to your assistant and see what it does, with and without the
masterclass skills. The masterclass walks the same ticket chapter by chapter.

**Then compare.** Every step of the worked answer, from the questions it should have asked to
the reviewed fix and what the team learned from it, is on the
[`solution` branch](https://github.com/limsijie93/tt-masterclass-agentic-sdlc/tree/solution/course/tickets/PROJ-142).

[`00-agents-draft.md`](00-agents-draft.md) is not part of the answer: it is the context file a
generator produces for this repository, used in chapter 2.1 to show why pruning matters.
